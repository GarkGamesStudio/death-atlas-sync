# Prueba de Sync 0.4.0

1. Sal del Sync anterior desde su bandeja. Extrae el nuevo ZIP: solo contiene DeathAtlasSync.exe.
2. Abre el EXE. Usa Detectar o Elegir carpeta; si aparecen varias cuentas, selecciona una.
3. Con WoW cerrado, pulsa OK después de leer el aviso de datos. Si la sincronización termina correctamente se oculta la ventana y aparece el agradecimiento. Si falla se muestra el error y puedes corregir la carpeta o reintentar.
4. En la bandeja comprueba Configurar, Acerca de y Cerrar. Acerca de incluye el repositorio público y las licencias integradas.

Las cuentas previamente registradas mantienen su configuración. Las nuevas conexiones públicas aún están cerradas durante la preparación de la beta. No borres la configuración para intentar resolver ese mensaje.

La casilla de inicio automático con Windows es opcional y se aplica después de sincronizar correctamente al pulsar OK. Para quitarlo, desmárcala y pulsa OK. No muevas el EXE si activas el inicio automático. La interfaz usa las preferencias de idioma de Windows y contiene los mismos 11 idiomas del addon, con respaldo en inglés.

La política 2026-11-01 requiere revisar el aviso y pulsar OK de nuevo. No borres la configuración anterior. Eliminar datos compartidos es opcional y retira realmente los aportes: no lo uses para comprobar una instalación que quieras conservar.
